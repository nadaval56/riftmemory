ANSS Comprehensive Earthquake Catalog (ComCat)

  The ANSS Comprehensive Earthquake Catalog (ComCat) contains earthquake
  source parameters and related products contributed by seismic networks
  around the world.

  Search The Catalog
  View Latest Earthquakes

Explore ComCat

Contribute Data

Use the Product Distribution Layer (PDL) to contribute earthquake data and products to USGS real-time systems and ComCat.

Access Earthquake Data

      Choose an interactive search, web service, real-time feed, notification
      service, or developer tool.

Data Availability

Review catalog date ranges by contributing seismic network.

Data Products

Learn how earthquake products are associated, versioned, and preferred.

Explore Catalog Sources

      See the authoritative and historical catalogs that contribute events to
      ComCat, including their time periods and geographic regions.

Browse Real-Time Contributors

      Find the seismic networks and agencies that contribute real-time event
      parameters and products.

Contribute Or Receive Earthquake Data

    Organizations can use the
    Product Distribution Layer (PDL)
    to send products to and receive products from the USGS.
